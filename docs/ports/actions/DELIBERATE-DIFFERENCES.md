# Deliberate differences

This table lists the places where the native session actions work differently from the Electron
app's TypeScript code on purpose. That code (`shared/new-session.ts`, `shared/worktree.ts`,
`shared/session-ids.ts`, `shared/priority.ts`, `shared/alias.ts`, `shared/settings.ts` for the apps
of Open project, `main/actions/claude-output.ts`, `process-info.ts`, `worktree-check.ts`,
`transcript.ts`, `project-apps.ts`, `terminal-launch.ts`, `actions.ts`, `app-icon.ts` and
`session-actions.ts`, `renderer/src/actions/action-model.ts`, `reasons.ts`, `errors.ts`,
`confirm.ts`, `confirm-step.ts`, `run-plan.ts`, `rename-model.ts`, `delete-notice.ts`,
`actions-context.tsx`, `ConfirmDialog.tsx`, `RenameDialog.tsx` and `RowMenu.tsx`, and
`renderer/src/sessions/new-session-form.ts` and `NewSessionDialog.tsx`) is the reference for what
the actions decide, not for how they get there. The last column says whether you'd notice the
difference in normal use, and a row marked "for the hands-on test" is one to check by hand in the
real app.

X2 is Hand over itself, now that it works, and X71 shows in the model of a session that Hand over
starts. X72 shows only in a note that holds a token, X73 only when a session's folder has gone
before its hand-over, and X74 only when the old session gets busy again while the new one starts.
X75 shows at every New session, when the dialog closes as the start begins. X4 is a row a user can
see, but only with names that use emoji or accents. X6 and X9 show only when a
`claude` command fails, X7 only in a race that's hard to hit, X10 only when a start of `claude --bg`
prints no short ID, and X11 and X13 only for a name, branch or folder with a hidden character in it.
X14 shows when an open uses Finder or fails, X16 only for a worktree in a review folder or on a
volume whose paths don't read in 2 seconds, and X18 for the terminal app icon of an external
session. X20 shows in Console, not in the window, X21 only when a Delete's `claude rm` takes too
long, is killed or outlives its Delete, and X22 only when the commits of a worktree change while its
Delete dialog is open. X23 to X28 cover the dialogs, the running state, the opener of the apps and a
Delete in a shared folder, and all six are visible, as are X29 and X30, which cover the Selected
Item panel and its send box. X31 shows for a moment after a session ends or starts, when Resume or
Delete waits for the session list to agree, in the first seconds after each start of Bifrost, when
Resume, Resume all or Delete of a parked session checks the list first, and when Resume all resumes
nothing because each session failed. X32 shows for a moment at each start, and for good only when
Bifrost can't find `claude`, and X33 only when you choose another action on a session in the seconds
after its Stop. The other rows change nothing on screen.
